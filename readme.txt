The code for particle filter is executed from file PF_CUPY_v2.py and the results from  the 
file are saved in resultspf.txt file

The file contains the following results
1) The execution time per data point for a single measurement update
2) The number of particles (N) used in testing of the algorithm 
3) The execution time of the algorithm with each value selected from N vector
4) The corresponding rmse values of latitude for each value of N
5) The corresponding rmse values of longitude for each value of N
6) The ground truth gps based position
7) The predicted latitude and longitude positions
